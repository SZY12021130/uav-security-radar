# 无人机安全文献雷达（UAV Security Literature Radar）

基于 **CCF 推荐国际学术会议和期刊目录（第七版，2026年3月）**，聚合 2024-01 至 2026-06 期间 CCF 目录内 **27 种期刊/会议**发表的 **395 篇无人机安全研究论文**，提供可交互的文献浏览、检索与计量可视化。

## 功能特性

- **期刊/会议折叠面板**：一个期刊或会议一栏，按发文量排序，点击展开该刊全部论文（标题、作者、年份、摘要、关键词、研究方向标签、DOI 链接、被引数）
- **分页浏览**：期刊/会议过多时自动分页（每页 9 栏）
- **站内检索**：全局跨库检索 + 每个期刊/会议下拉框内的独立检索（支持标题/摘要/作者/关键词，空格多词与逻辑）
- **排序功能**：支持按时间（新→旧 / 旧→新）与被引量排序
- **年份趋势**：每个期刊/会议面板内嵌 2024–2026 发表趋势图
- **统计可视化**：发文量排行（按 CCF-A/B/C 着色）、Top 8 期刊年份堆叠趋势、研究方向分布环图
- **筛选器**：期刊/会议类型、CCF 等级、研究方向标签多维度筛选

## 数据说明

| 项目 | 说明 |
|------|------|
| 时间范围 | 2024-01-01 ~ 2026-06-30 |
| 论文总量 | 395 篇（经安全相关性二次过滤） |
| 覆盖阵地 | 27 种 CCF 期刊/会议（TDSC、TIFS、TMC、JSAC、TWC、IEEE IoTJ 等） |
| 数据来源 | OpenAlex API、dblp API、Semantic Scholar API |
| 数据文件 | `public/uav_sec_data.json` |

采集流程：OpenAlex/dblp 双源交叉检索（UAV/drone/FANET 标题词 × 20+ 安全词）→ 按来源映射回 CCF 目录 → Semantic Scholar 补全摘要 → 强安全词表二次过滤 → 规则分类器标注研究方向（认证与密钥协议、隐私计算与联邦学习、物理层安全、入侵检测与AI安全、蜂群组网、欺骗导航、区块链信任、反无人机探测等）。

## 本地运行

```bash
npm install
npm run dev      # 开发预览
npm run build    # 构建到 dist/
```

## 配套报告

`docs/无人机安全研究方向调研分析报告.pdf` —— 13 页调研报告，含文献计量分析、八大方向技术路线梳理、密码学×AI 交叉选题建议与投稿策略（目录可点击跳转）。

## 数据更新

如需增量更新（如补充 2026 下半年论文），按上述采集流程重跑 OpenAlex/dblp 检索，归并去重后替换 `public/uav_sec_data.json` 并重新构建即可。
